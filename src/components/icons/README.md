# Пиктограммы

Иконки в Печатниках — единственный носитель смысла: подписей у кнопок нет,
только всплывающая подсказка, а на тач-устройствах нет и её. Поэтому каждая
пиктограмма отвечает за свою кнопку на сто процентов.

Весь набор живёт в `index.jsx`. Локальных иконок в компонентах быть не должно:
раньше они лежали в пяти файлах, и часть была продублирована под разными
именами (`IconWrench`/`IconSettings`, `IconImage`/`IconImg`,
`IconFootnote`/`IconFootnoteList`, два разных `IconClose`).

## Правила набора

| Правило | Значение |
| --- | --- |
| Сетка | `viewBox="0 0 16 16"` |
| Толщина обводки | `1.5` |
| Концы и стыки | `round` |
| Способ отрисовки | контур; заливка — только для точек-маркеров |
| Размер в кнопке | 16px (проп `size` для исключений) |
| Минимальная деталь | не меньше 2px в рабочем размере |
| Плотность | 15–35%, разброс по набору не больше 2,5× |

`npm run check:icons` проверяет сетку, толщину, отсутствие текстовых глифов
и то, что иконки не объявлены мимо этого модуля. Плотность скрипт не считает:
статически её честно не получить, а тянуть в проект растеризатор ради одной
проверки не стоит. Замер делается вручную в браузере — рисуем каждую иконку
в 64×64 на canvas и считаем долю непрозрачных пикселей.

Разброс важнее среднего: если одна иконка заполняет 45% площади, а соседняя
14%, ряд перестаёт читаться как набор, даже когда каждая по отдельности
нарисована аккуратно.

| | было | стало |
| --- | --- | --- |
| Минимум | 13,9% (сноска) | 15,0% (курсив) |
| Медиана | ~25% | 24,8% |
| Максимум | 45,5% (таблица) | 35,2% (встроить) |
| Разброс | 3,28× | 2,35× |

Коридор 22–30%, заложенный в ТЗ, в этой стилистике недостижим: рамка
11×10 при обводке 1,5 сама по себе даёт около 25% площади, и любая деталь
внутри выводит иконку за верхнюю границу. Поэтому иконки с рамкой
(изображение, встраивание, таблица) держим у верхнего края коридора,
а открытые формы — у нижнего.

## Чего в наборе нет

**Текстовых глифов — кроме одного.** Глиф сидит на базовой линии текста,
а не в оптическом центре кнопки, и весит иначе, чем соседние векторные
значки. Так «B» шрифтом Georgia стала вектором «Ж» (`IconBold`).

Исключение — `IconTypograf`: кнопка расставляет типографские знаки,
и на ней уместен настоящий знак, а не его чертёж. Нарисованные шевроны
выходят угловатыми и вдобавок похожи на «Код». Список исключений задан
в `scripts/check-icons.mjs`; любой глиф вне списка роняет проверку.

**Совпадающих силуэтов.** Проверяйте новую иконку рядом с соседями по панели
при 16px, а не при 64. Что было исправлено:

| Было | Читалось как | Стало |
| --- | --- | --- |
| Шестерёнка «Настройки» | солнце — две окружности и восемь отстоящих лучей, рядом с настоящим солнцем темы | ползунки |
| Незамкнутый круг «Дзен» | индикатор загрузки | экран со строкой |
| Гамбургер «Документы» | главное меню | стопка листов |
| Маркированный список «Оглавление» | тот же список, что в тулбаре | ступенчатые строки |

**Предметов вместо действий.** Если кнопка что-то делает, это должно быть
в рисунке: папка со стрелкой внутрь — «переместить», папка с плюсом —
«создать», лист со стрелкой наружу — «выгрузить».
